# AC-06 — Cache e distinção de erros

Veredito: **FAIL**.

Primeira metade (cache) cumprida. Segunda metade (distinção de erros) violada.

Medido no build de produção com `SANITY_DATASET=dataset-inexistente-validacao-falha-20261009`
(indisponibilidade real do Content Lake, HTTP 404 no log do servidor):

```
/artigos/slug-inexistente-*                 -> HTTP 200, cache-control: private, no-store
/artigos/drafts-artigo-rascunho-sem-preview -> HTTP 200, cache-control: private, no-store
/                                          -> HTTP 200, cache-control: no-store
```

Falha de infraestrutura (Content Lake indisponível) está sendo **mascarada como soft
200** exibindo a UI de 404 (`app/not-found.tsx`), em vez de responder status de erro
adequado (503/500). `app/error.tsx` não foi acionado. `isArticleAccessible` engole o
erro e devolve `true` (`lib/preview/auth.ts:167`), o que transforma falha de
infraestrutura em "não encontrado".

Cache `no-store`/`private, no-store`: **cumprido**. Distinção de erros: **violada**.
AC consolidado = FAIL.
