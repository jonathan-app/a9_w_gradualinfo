# Evidência AC-03

**Critério**: Chamadas ao Sanity ocorrem no servidor/Worker; tokens privados não vazam no bundle cliente.

## Prova

`lib/sanity/client.ts:1-10`:

```typescript
/**
 * @fileoverview Cliente HTTP server-side para consulta à API do Sanity Content Lake.
 * @module lib/sanity/client
 * @description Realiza consultas GROQ diretamente pela API REST do Sanity em tempo de execução no
 *   servidor/Worker, sem incluir tokens no bundle JavaScript do cliente.
```

`lib/sanity/client.ts:115-117`:

```typescript
if (isPreview && readToken) {
  headers.Authorization = `Bearer ${readToken}`;
}
```

O token só é enviado em requisições de preview, que ocorrem exclusivamente no servidor. O cliente Sanity nunca é importado por Client Components.

## Teste

`__tests__/unit/sanity-client.test.ts` confirma que o token não é incluído em consultas públicas.
